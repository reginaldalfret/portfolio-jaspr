# Reginald Alfret V — Portfolio (Jaspr) 🎯

> **Dart 3.13** · **Jaspr 0.23 SSR & Hydration** · **Tailwind CSS** · **Obsidian Liquid-Glass Design**

A high-performance portfolio application built with [Jaspr](https://docs.page/schultek/jaspr), the modern Dart web framework that brings Flutter-style reactive components to pure HTML, CSS, and JavaScript with server-side pre-rendering (SSR) and client hydration.

## 🚀 Live Demonstration
- **Multi-Stack Live Container**: [https://reginaldalfret.tech/?stack=jaspr](https://reginaldalfret.tech/?stack=jaspr)
- **Direct Jaspr Website**: [https://reginaldalfret.tech/stacks/jaspr](https://reginaldalfret.tech/stacks/jaspr)

## 🛠️ Architecture & Features
- **Server-Side Rendering (SSR)**: Pre-renders complete, SEO-friendly HTML on the server.
- **Client-Side Hydration**: Re-hydrates stateful interactive components on the client in pure Dart.
- **Obsidian Dark Liquid Glass Theme**: Jet-black background (`#050505`), backdrop blur, translucent cards, and emerald accent gradients.
- **Interactive Resume Mode**:
  - 30 Merged PRs across Apple, Google, Microsoft, Meta, AWS, NVIDIA, NASA, and Netflix.
  - Category filters: All, Big Tech, AI/ML, Cloud & Infra.
  - Work Experience & Featured Technical Projects.
  - Awards, Symposia Wins & Industry Certifications.
- **Embedded PDF Viewer**: Dual-view toggle to switch between interactive DOM and original 1-page visual PDF.
- **11-Stack Floating Dock**: Seamless navigation across all 11 production implementations (Next.js, Nuxt 3, Django, Spring Boot, Laravel, Rails, Angular, Blazor, Buffalo, Leptos, and Jaspr).

## 💻 Local Development
```bash
# 1. Install Dart SDK (3.10+)
dart --version

# 2. Activate Jaspr CLI
dart pub global activate jaspr_cli

# 3. Install dependencies
dart pub get

# 4. Run development server
dart pub global run jaspr_cli:jaspr serve --port 8091

# 5. Build for production (Static SSR)
dart pub global run jaspr_cli:jaspr build --port 8091
```
