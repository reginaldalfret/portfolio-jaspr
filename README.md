### 4. Prerequisites & Local Development

#### Prerequisites
- Dart SDK 3.3+, jaspr_cli

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-jaspr.git
cd Portfolio-Jaspr
dart pub get
```

#### Running Development Server
```bash
jaspr serve
```

#### Production Build
```bash
jaspr build
```

#### Running Test Suite
```bash
dart test
```
